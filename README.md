# nkf — NongKept web app (static front-end)

หน้าเว็บ static ของแอป NongKept (จังหวะรีวิวรายการจากอีเมลธนาคาร)
- ตัวหน้านี้ = UI ล้วน ๆ ไม่มีข้อมูล/ความลับ — ข้อมูลอ่าน/เขียนผ่าน Supabase (anon key + RLS) หลังล็อกอิน
- ไม่มี session → หน้าล็อกอิน (อีเมล+รหัสผ่าน) · เปิดแบบ file:// หรือ ?demo=1 → โหมดเดโม่ ไม่ต้องล็อกอิน
- ลืมรหัสผ่าน: ปุ่มในหน้าเข้าสู่ระบบส่งอีเมลรีเซ็ต (Supabase Auth) — ลิงก์กลับเข้าหน้า "ตั้งรหัสผ่านใหม่" ของแอป
  (ต้องเพิ่ม Redirect URL ของเว็บนี้ใน Supabase dashboard · ถ้าไม่ได้ เพิ่มลิงก์จะ fallback ไป Site URL เดิม)
- นำเข้า statement (วางข้อความ / ไฟล์ .txt .csv / ไฟล์ PDF — ถอดรหัสในเครื่องด้วย pdf.js) เขียน Supabase ตรงผ่าน RPC `ingest_statement` — ตรวจแถว/กันซ้ำ/ข้ามเงินเข้า/แคป 300
- แจ้งเตือนผ่านบอท/ดีบัก ยังพึ่งลิงก์ส่วนตัวเดิม (#k=...) — ยังไม่ย้ายมาโหมดนี้
- บิลแชร์ (b/#<token>): หน้าเพื่อนเปิดจากลิงก์ ไม่ต้องสมัคร — เห็นเฉพาะบิลนั้น + ติ๊กของตัวเอง (ฟังก์ชัน bill_share_* ใน migration 0012 · anon ไม่มีสิทธิ์ตารางใด)
